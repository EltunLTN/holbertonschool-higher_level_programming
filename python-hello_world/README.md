# Python - Hello, World

This directory contains introductory Python exercises from the Holberton Higher Level Programming curriculum. Tasks cover basic printing, string manipulation, and simple formatting.

## Learning Objectives

- Use `print()` with strings, integers, and floats
- Concatenate strings and work with string indexing
- Format output with f-strings and escape sequences

## Files

- `2-print.py`: Prints a string followed by a newline
- `3-print_number.py`: Prints an integer using string formatting
- `4-print_float.py`: Prints a float with two decimal places
- `5-print_string.py`: Prints a string multiple times using multiplication
- `6-concat.py`: Concatenates two strings
- `7-edges.py`: Slices characters from the beginning and end of a string
- `8-concat_edges.py`: Combines edge slices from two strings
- `9-easter_egg.py`: Prints the Zen of Python

## Requirements

- Python 3.x
- PEP 8 style (pycodestyle)
- Files should be executable where required

## Usage

Run any script with:

```bash
python3 2-print.py
```

Or make executable and run directly:

```bash
chmod +x 2-print.py
./2-print.py
```
