# Python - If/Else, Loops, Functions

This directory contains Python exercises on control flow, loops, and functions from the Holberton Higher Level Programming curriculum.

## Learning Objectives

- Use `if`, `elif`, and `else` for conditional logic
- Write `for` and `while` loops
- Define functions with parameters and return values
- Practice common algorithmic patterns (FizzBuzz, powers, digit extraction)

## Files

- `0-positive_or_negative.py`: Prints whether a number is positive, zero, or negative
- `1-last_digit.py`: Defines `last_digit(n)` — returns the last digit of a number
- `2-print_alphabet.py`: Prints the lowercase alphabet
- `3-print_alphabt.py`: Prints the alphabet except `q` and `e`
- `4-print_hexa.py`: Prints numbers 0–98 in hexadecimal
- `5-print_comb2.py`: Prints two-digit combinations from 00 to 99
- `6-print_comb3.py`: Prints unique two-digit ascending combinations
- `7-islower.py`: Defines `islower(c)` — checks if a character is lowercase
- `8-uppercase.py`: Defines `uppercase(str)` — prints string in uppercase without `upper()`
- `9-print_last_digit.py`: Defines `print_last_digit(number)` — prints the last digit
- `10-add.py`: Defines `add(a, b)` — returns the sum of two integers
- `11-pow.py`: Defines `pow(a, b)` — returns a raised to the power of b
- `12-fizzbuzz.py`: Defines `fizzbuzz()` — prints FizzBuzz for numbers 1–100
- `100-print_tebahpla.py`: Prints the alphabet in reverse lowercase
- `101-remove_char_at.py`: Defines `remove_char_at(str, n)` — removes character at index n

## Requirements

- Python 3.x
- PEP 8 style (pycodestyle)
- Files should be executable where required

## Usage

Run any script with:

```bash
python3 12-fizzbuzz.py
```

Example with arguments:

```bash
python3 101-remove_char_at.py
```
